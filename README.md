# Auction

A marketplace web app built with Django where users can create listings, place bids, and keep track of items they're interested in.

This was my CS50W Project 2, and it was one of my first projects where I worked with Django and built a complete web application.

## Features

* User registration and login
* Create and manage listings
* Place bids
* Watchlist
* Categories
* Listing comments
* Close listings and determine the winner

## Tech Stack

* Python
* Django
* HTML
* CSS
* JavaScript
* SQLite
* Jinja


## Running locally

```bash
git clone https://github.com/LynxQuas/Auction.git
cd Auction

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Then open `http://127.0.0.1:8000`.
